# 默认动画工程：灵感开始流动

为 AIScripter for ani 专门设计的 18 秒品牌短片。1920 × 1080、30 fps、540 帧，三幕各 6 秒。它既是一段可以直接播放和导出的作品，也是外部 AI 续改、人工编辑与组件复用的创作起点。

## 分镜与视觉

| 时间 / 全局帧 | 画面 | 动作与声音 |
| --- | --- | --- |
| 0–6 秒 / 0–179 | 「让灵感，开始流动。」；左侧大标题，右侧软件图标 | 标题缓入，三条薄荷绿与紫色椭圆光轨环绕图标；配乐从 D 大调和弦开始 |
| 6–12 秒 / 180–359 | 「把想法拆开，让细节发光。」；节奏、层次、色彩三张卡片 | 卡片错开入场，波形流动、平面浮动、色彩交叠；和声转入 B 小调 |
| 12–18 秒 / 360–539 | 「你的创意，现在开始。」；居中图标与品牌签名 | 环绕动作延续，标题自然出现并停留；和声落在 G 大调，音乐渐出 |

深蓝渐变、细网格、稀疏星点作为背景；主色 `#75efd3`，辅色 `#a58aff`。画面留有 160 px 左右安全边距，底部细线提示短片进度。场景接缝使用直接切换，各幕保留一致的背景、品牌位置和全局运动时间。播放需用户操作，不会在启动时自动发声。

## 打开与保留修改

启动软件会打开独立的默认工程副本，停在第 75 帧供观察；播放完整动画前可把播放头移到起点。工程菜单 → **打开新版示例工程** 会另建一份干净副本。

默认副本位于 Electron 用户数据目录的 `default-animation-project/`。旧的 `sample-project/`、太阳系源码示例和人工修改保留。后续默认模板更新时，只有仍与复制基线一致的副本才自动刷新，刷新前保留完整备份；已编辑的副本继续使用。工程目录中的隐藏 `.aiscripter/bundled-sample.json` 只记录模板复制基线，外部 AI 不应修改。

## 可编辑入口

- **文字图层**：每幕的大标题与副标题都是普通文字图层，可直接修改文案、位置、字体和入场关键帧。第一幕主标题稳定 ID 为 `intro-title`。
- **程序场景参数**：选择左侧「程序场景」。`accent` 改主色，`secondary` 改辅色，`energy` 调节连续运动速度；可添加参数关键帧。
- **光轨组件**：第一幕展开 `hero`，选择 `hero-orbit`；第二幕选择 `craft-orbit`；第三幕展开 `finale`，选择 `finale-orbit`。实例参数可调整尺寸与两种颜色，画布操作可修改位置、缩放和旋转。
- **卡片组件**：第二幕选择 `card-rhythm`、`card-depth`、`card-color`。分别设置标题、文案、强调色、运动幅度与图形样式，实例之间互不影响。文案建议控制在约 18 个汉字以内，以适配当前卡片宽度。
- **音轨**：`First Light` 是贯穿三幕的全局配乐，支持移动、裁剪、淡入淡出、静音和音量调整。

`scripts/*.ts` 是每幕入口，`components/motion.ts` 是共享布局与动作实现，`assets/cards.json` 是卡片默认文案。当前作品为 Canvas 2D 程序场景加普通文字图层。每帧由整数帧时间直接求值；资源与渐变纹理只在初始化时加载、制作，逐帧渲染不累积状态。

## 外部 AI 续改约定

先读取工程当前版本和 [v3 规范](../../docs/project-format-v3.zh-CN.md)。保留场景、文字图层、程序对象和组件实例的稳定 ID，保留 `program.edits` 中的人工覆盖。只改背景或卡片动画时，不要重建场景，也不要覆盖普通文字图层。

三幕共享 `components/motion.ts`：修改它会影响所有引用场景。可在各入口创建独立组件版本，或通过参数仅调整其中一幕。改变时长、重排或复制场景时，全局音轨保持自己的时间位置；本作品的页脚进度和幕间连续运动按原始 18 秒分镜计算，改变叙事结构后须同步调整共享代码中的幕起始时间与总时长。

## 素材与验证

`assets/brand-icon.png` 原样复制用户提供的 `AIS-icon.png`。显示时由 Canvas 按其原有图标边界取景，不修改源文件。配乐 `assets/first-light.wav` 是本项目合成的原创音轨，没有网络素材或在线依赖。复现资源：

```powershell
node scripts/generate-default-demo-assets.mjs
npm run validate:project -- examples/default-animation --strict-assets --build
npm run test:default-demo
```

资源生成命令从仓库根目录运行，仅更新此模板的素材；不会修改用户数据中的副本。原生 Electron 验证覆盖三幕、两处接缝、同帧重复渲染、预览隔离、文字编辑、独立实例参数、保存重读、缩略图与波形，以及另建副本保留人工修改。完整 MP4 输出到 `artifacts/default-animation.mp4`，画面截图与报告在 `.qa/default-animation/`；FFmpeg 解码检查 540 帧、1080p、30 fps、18 秒、H.264/AAC 与非静音配乐。
