# AI 创作优化：第二轮实施记录

日期：2026-10-02。当前应用源码版 0.1.0，工程格式支持 v1/v2/v3，程序运行接口与 SDK 1.0.0，MCP 服务 0.3.0（18 项工具）。本轮交付优化路线第 2 阶段的程序场景基础。字段以 [v3 规范](project-format-v3.zh-CN.md)为准。

## 已交付

| 部分 | 实际能力 |
| --- | --- |
| 工程契约 | v3 Schema、固定接口/SDK 版本和能力声明；新旧场景混排；显式采用后升级；升级前完整可见工程备份 |
| 类型化构建 | 严格 TypeScript 检查、文件/行/列诊断、工程内 `.ts` / `.mjs` 模块、固定 SDK 打包、构建缓存 |
| Canvas 对象 | 分组、形状、文字、图片、自定义画面；父子变换、透明度、可见性、锚点和矩形裁切；稳定 ID 与结构检查 |
| 动画函数 | 插值、缓动、解析弹簧、路径、错峰、循环、简单布局、种子与通道随机、噪声 |
| 资源 | 初始化期间只读预加载数据、图片及项目字体；SVG 在同一隔离渲染器栅格化后传入 Worker |
| 生命周期 | create/evaluate/render/dispose；每窗口最多 6 个常驻实例；代码/修订/种子/上下文变化时重建；超时和异常终止实例后恢复 |
| 预览恢复 | 串行绘制；新草稿可取消旧程序渲染；过期请求不再覆盖可见画面 |
| 编辑器 | 添加程序场景、实例参数与种子、模块编辑、编译诊断、重建预览；统一草稿/撤销/保存 |
| MCP | `enable_programs` 变更、`.ts` 与 components/ 源代码、`build_project`、编译诊断、实例与帧耗时信息 |
| 混合输出 | 程序场景与原生场景、原生覆盖图层和跨场景音轨共同逐帧导出 |

备份纳入保存事务，素材使用文件复制暂存，避免把全部素材同时装入内存。v1/v2 custom 图层继续每帧建立 Worker，不改变原来的 setup、随机种子和 render 接口。

- MCP 两版协议、无工程文档读取、v2/v3 离线修改/修订冲突/持久撤销通过；v3 SDK 文档、组件读取和构建调用通过。

- 编辑器内实例参数修改、TypeScript 模块打开、错误定位、保存后重开及全局跳帧均已检查。
- 完整混合工程解码为 **450 帧、1920×1080、30 fps、15 秒视频，H.264 与 AAC**。当前本机编码器的封装时长为 15.02 秒，包含 AAC 音频包的取整尾部；视频帧数与视频时长准确。
- 旧版实际 Electron/MCP 编辑闭环 8 项检查通过，保留人工属性、撤销/重做、诊断、取消与保存。

产物位于 `artifacts/qa-program-scenes.png`、相邻 JSON、`.frame.png`、`.preview.mp4`，完整导出位于 `artifacts/qa-program-full.mp4`，其 `.verification.json` 记录解码结果。旧版回归产物仍为 `artifacts/qa-ai-loop.png` 及相邻文件。测试使用独立临时工程与用户数据目录，不修改原始示例；项目字体测试仅复制本机系统字体到临时工程，不随示例分发。

示例含 126 个对象：一个原生标题场景及一个程序场景（卡片组件、100 个背景粒子、JSON 数据和 SVG），共 15 秒。一次验收观察到首个程序截图 33 ms、后续 5–10 ms，包含 PNG 截图处理；这是此示例和本机的观察值，不代表任意复杂场景的帧率保证。机器条件沿用[首轮基线](ai-creation-phase-1.zh-CN.md)。

## 下一轮：组件与人工编辑桥接

目前程序代码内部对象还不能在画布中直接选中。第三轮应接入：

1. 对象树、世界边界、命中测试及画布控制柄。
2. 类型化公开参数描述、组件实例配置与参数关键帧。
3. 按稳定对象 ID 保存“替换值/相对偏移”的人工覆盖。
4. 代码更新后重新绑定覆盖，保留并提示对象消失或类型变化产生的未绑定项。
5. 对象/覆盖锁定、MCP 差异与变更检查，以及人工修改在 AI 续改后的端到端验收。

连续模拟与状态快照、新 Three.js 适配、SDK 视频节点、DOM/React 场景、第三方依赖安装、并行作业和大规模压力测试仍在后续阶段。开发者必须使 evaluate 仅依赖当前帧与显式输入；软件不会自动把有状态 JavaScript 转换为确定性模拟。
