# AI 创作优化：首轮实施记录

日期：2026-10-02。本文记录首轮交付时的 v1/v2 与 MCP 0.2.0 基线；当前第二轮新增能力见 [v3 规范](project-format-v3.zh-CN.md)。首轮交付第 0 阶段的兼容与性能基线，以及第 1 阶段在 v2 上的可用创作闭环。

## 已交付

| 部分 | 实际能力 |
| --- | --- |
| 工程服务 | 按场景/图层 ID 修改；stage 校验；草稿与磁盘双修订检查；锁定保护 |
| 草稿桥接 | Windows 命名管道与当前用户权限令牌文件；读取人工未保存的属性和脚本 |
| 编辑器 | AI 一组结构和脚本修改形成一条撤销记录；正常撤销/重做；自动保存和立即保存 |
| 持久化 | 整批场景、清单和脚本的暂存、原文件备份、日志、提交标记、进程中断恢复；离线提交具有持久撤销 ID |
| 素材 | base64 导入新素材，更新修订基线；同名覆盖和越界路径被拒绝 |
| 视觉反馈 | 冻结草稿，隐藏渲染指定全局帧，返回 MCP PNG、局部帧映射、耗时和定位信息 |
| 运行诊断 | 场景 ID、图层 ID、脚本/素材路径、局部帧、异常消息及可用的堆栈 |
| 短片作业 | 960×540 H.264/AAC、最多 30 秒；排队、进度、结果、取消；与普通导出共享串行调度 |
| 接入规范 | 保留旧 4 项工具，扩展为 17 项；更新外部 AI 创作规范和软件复制规范入口 |

使用方法和所有参数见[本机 MCP 服务](mcp-local.zh-CN.md)。新导入的素材和已保存新增模块在撤销后保留为未引用文件；旧源代码、结构与引用恢复。不会自动清理用户代码。

## 验收记录

### 自动化

- `npm test`：14 个文件，49 项测试通过。包含 stage 不修改磁盘、人工值保留、锁定拒绝、草稿/磁盘修订冲突、离线提交与撤销、路径拒绝、素材导入、管道认证，以及工程复制时保留目标会话。
- 事务验证：在三处文件写入后注入失败，整批旧内容恢复；模拟准备日志中断、提交前进程中断和提交标记后的恢复；拒绝活动写入锁。

- `npm run test:mcp`：两种 MCP 协议版本握手、17 项工具、文档模式、工程检查、越界拒绝、离线 stage/commit、过期修订拒绝和持久撤销通过。

读取 37、149、150、299、37 全局帧，接缝映射分别为 introduction 的 149 和 orbit 的 0。重复第 37 帧的 PNG 完全一致。截图前后播放头保持 37，预览 webContents ID 不变。一次撤销同时恢复背景参数和原有脚本，标题位置保留；重做恢复 AI 背景。保存后重新加载仍一致。

### 基线机器与测量范围

Windows 10.0.26200 x64；Intel Core i7-14650HX，24 个逻辑处理器，16 GB 内存；Electron 43.4.0、Chromium 150.0.7871.224、Node 24.18.1。输入示例修订：`9d7b56d957ce6e30bddd2db351063f95cc79c9ad8a19a4b5b97d153d63833ca8`。

本轮 960×540 的五次截图单帧渲染为 19–33 ms。这个值包含指定帧绘制和 PNG 捕获，不包含前面的工程复制、窗口启动和 MCP 传输。短片端到端联调约 1.4 秒，含排队、16 帧编码及取消检查；它是此测试工程的结果，不代表复杂场景的速度。下一阶段应增加大素材、粒子、3D 和长时间播放的独立基线。

## 复现

```powershell
npm test
npm run test:mcp
npm run test:ai
```

`test:ai` 创建独立工程副本和浏览器配置，通过实际 Electron 与 MCP 执行上述闭环，输出到 `artifacts/qa-ai-loop.png*`；测试退出后清理自己的临时工程。需要能够正常启动 Electron GPU 子进程的本机环境，受限执行环境可能无法完成 GUI 验证。

## 下一阶段与当前边界

下一阶段开始 v3：明确场景入口和类型化 SDK，增加常驻生命周期，再建设对象树、组件实例、公开参数和人工覆盖。现有 v1/v2 保持每帧独立 Worker 的语义，不隐式升级生命周期或随机规则。

当前 MCP 运行反馈来自显式截图；不提供 TypeScript 构建诊断、自动迭代代理或 v3 覆盖诊断。渲染任务串行，单帧最多 6 张、单片段最多 30 秒；复杂任务需分批。会话短片在编辑器退出时清理，交付前应复制。事务验证覆盖进程中断，未声称 Windows 突然断电时具有数据库级持久性保证。

保存副本、示例刷新和历史复制排除 `.aiscripter/` 会话元数据，恢复历史不会覆盖当前会话令牌。动画运行时拒绝读取点号开头的工程私有路径。
